# 拿破仑传奇 (Napoleon Legacy)

这是一款基于 Web 的 3D 互动历史游戏。玩家将扮演拿破仑，在波澜壮阔的历史转折点做出抉择。你的每一个决定都会影响各项数值（战略、外交、忠诚、名留青史、人道关怀），并最终导向不同的历史结局。

## 🌟 核心特性

- **轻量级 3D 渲染**: 基于 Three.js，无需下载，在浏览器中即可体验历史战役的 3D 场景。
- **网状剧情分支**: 由全新的数据驱动 **PlotEngine (剧情引擎)** 支持。从硬编码剧本全面转向图结构（Graph）的数据驱动模式，支持复杂的条件判断、剧情锁、多线分支和循环。
- **动态场景事件**: 突破纯文本交互，玩家在剧情中的选择可以直接触发 3D 场景中的事件（例如：炮兵开火时的火光闪烁与屏幕震动）。
- **纯原生支持**: 核心逻辑和测试框架均使用原生 JavaScript 构建，极致轻量。

## 📁 目录结构

```text
src/
├── core/         # 核心引擎 (GameEngine 3D驱动, PlotEngine 剧情引擎, GameState 状态管理)
├── data/         # 数据配置 (plotData.js 存放剧本节点的图数据)
├── scenes/       # 3D 场景 (各章节的场景搭建、事件回调 handleEvent)
├── dialogue/     # UI 表现层 (DialogueSystem 负责渲染剧情节点的 UI)
├── characters/   # 角色模型生成
├── controls/     # 键鼠与移动端触控逻辑
└── tests/        # 单元测试
```

## 🛠️ 本地运行与测试

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 运行单元测试
```bash
npm test
```
